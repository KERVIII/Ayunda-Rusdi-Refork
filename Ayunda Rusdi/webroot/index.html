01About

Ayunda Rusdi Color Enhancer is an open-source root module that adjusts display saturation through SurfaceFlinger, with optional system animation-scale tweaks.

This project is a fork and independent continuation of the original Ayunda Risu Color Enhancer.

04What It Changes

Color: one SurfaceFlinger saturation call (transaction 1022). It does not touch frame-rate, refresh-rate or any other display property.

System UI Tweaks (optional): the three global animation scales, backed up first and restored on request, on Reset, or on uninstall. No background service runs.

Pinned presets and per-app profiles are small files in the module's state folder. Profiles switch automatically through one small event-driven listener that runs only while a profile exists and auto switching is on (no polling); Apply also sets a profile on request.

Reset

This clears the saved preset and restores native colors.
