01About

Ayunda Risu Color Enhancer is an open-source Magisk module designed to enhance Android display colors, saturation, and brightness.

This project is a fork and independent continuation of the original Ayunda Risu Color Enhancer.

07Compatibility

This module's only system modification is a single SurfaceFlinger saturation call (transaction 1022). It does not touch frame-rate, refresh-rate, or any other display property.

If you also run Zetamin, note that Zetamin's own installer explicitly recommends not combining it with other screen tweaks. The two modules touch unrelated properties, but that guidance applies regardless of which other module you're pairing it with.

Reset

This clears the saved preset and restores native colors.
